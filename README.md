# Push updates to github
> STEP 1: Add the changed file
- git add .

> STEP 2: Write a commit message
- git commit -m "update readme file"

> STEP 3: Push command
- git push origin main


- git add . && git commit -m "update readme file with clone instruction" && git push origin main

# Pull updates
> STEP 1: Get new updates
- git pull
